# Split Plan: Kokoro Streaming TTS Playback MVP

## 1. Objective

Break the streaming TTS MVP into small implementation slices that keep file-output synthesis stable and avoid unrelated module changes.

## 2. Slice 1: Rust Contract Models

Files:

- `tauri-plugin-voice/src/models.rs`
- `tauri-plugin-voice/tests/smoke_contract.rs`

Work:

- Add stream request and response models.
- Add stream event models.
- Add cancel request and response models.
- Add serialization smoke tests.

Validation:

- Run Rust smoke contract tests.

## 3. Slice 2: Commands and Permissions

Files:

- `tauri-plugin-voice/src/commands.rs`
- `tauri-plugin-voice/src/lib.rs`
- `tauri-plugin-voice/permissions/default.toml`
- `tauri-plugin-voice/permissions/autogenerated/commands/*`

Work:

- Register `stream_speech`.
- Register `cancel_speech`.
- Add command permissions.
- Regenerate schemas if the project workflow supports it.

Validation:

- Confirm command names appear under the `plugin:voice|...` namespace.

## 4. Slice 3: Worker Stream Protocol

Files:

- `tauri-plugin-voice/scripts/tts_worker.py`

Work:

- Add `mode = stream` handling.
- Convert generated audio to PCM16.
- Chunk PCM by requested duration.
- Emit ordered stream lifecycle lines.
- Accept cancel messages.
- Suppress chunks after cancellation.

Validation:

- Run model-free protocol tests if available.
- Manually inspect emitted JSON shape with a fake or short generation path if feasible.

## 5. Slice 4: Rust Stream Forwarding

Files:

- `tauri-plugin-voice/src/desktop.rs`

Work:

- Add active stream state.
- Validate streaming requests.
- Send streaming worker requests.
- Forward worker stream lines to `tauri-voice-plugin://tts-stream`.
- Implement cancellation.
- Suppress stale or cancelled chunks.
- Preserve file-output synthesis behavior.

Validation:

- Run Rust tests.
- Manually stream a short phrase once dependencies are available.

## 6. Slice 5: Guest JS Playback Helper

Files:

- `tauri-plugin-voice/guest-js/index.ts`

Work:

- Add stream and cancel types.
- Add `streamSpeech`.
- Add `cancelSpeech`.
- Add `listenToTtsStream`.
- Add `playStreamedSpeech` with Web Audio buffering.
- Clean up listeners and playback on complete, error, or cancellation.

Validation:

- Run the guest-js build.
- Verify TypeScript types compile.

## 7. Slice 6: Docs and Example Usage

Files:

- `tauri-plugin-voice/README.md`
- `tauri-plugin-voice/USAGE.md`

Work:

- Document explicit streaming mode.
- Document file-output fallback.
- Document event metadata.
- Document cancellation behavior.
- Keep direct native playback out of scope.

Validation:

- Read docs for consistency with public model names.

## 8. Final Validation

Run:

- Rust tests.
- Guest JS build.
- Manual streaming playback.
- Manual cancellation.
- Manual file-output fallback check.

Do not move the Plane item to Done until the implementation is complete, validated, and the user confirms it is done.
